How it worksNo. 002

三个动作，文件留在电脑里。

01 / PASTE

粘贴链接

短链、完整链接、作品 ID 都可以。整段分享文案直接粘进来，页面会自动找出链接。

02 / RESOLVE

本地解析

请求只发往 127.0.0.1 上的本地引擎，作品信息不经过第三方解析站，也不需要登录快手。

03 / SAVE

直接保存

视频、原声、封面从官方 CDN 下载。保留原始画质；没有原声文件时，可从视频音轨提取 WAV。

python server.py  →  http://127.0.0.1:8787
